# McMillan notes — source material for S7

Extracted 2026-08-19 from the user's own copy of Lawrence McMillan's
*Options as a Strategic Investment* (5th ed.), at the user's explicit
request: "please dont go cherry picking in your memory... can you read
the book and derive strategies we need?"

The epub was converted to plain text (43 chapters, ~390,000 words) and
read in full across 8 parallel passes, each producing one of the files
below. Every quote in every file traces to the actual text — where a
source file was thin, cut off mid-chapter (a few were, across a 60-file
epub split), or simply didn't cover something, that is stated explicitly
rather than filled in from training-data familiarity with this book.

The synthesis and the parts of this actually adopted into the live S7
strategy live in `strategies.md`'s S7 section, not here — these files are
the primary-source reference underneath that synthesis, kept in full
because a 350KB set of real, quoted chapter notes is worth more than a
compressed summary once you need to go check "what exactly did he say
about X."

| File | Chapters | Topic |
|---|---|---|
| `01_calls_basics.md` | 1–6 | Definitions, covered call writing, call buying, naked/ratio call writing |
| `02_call_spreads.md` | 7–14 | Bull/bear/calendar/butterfly/ratio/reverse/diagonal call spreads |
| `03_puts.md` | 15–21 | Put mechanics, put buying, protective puts, straddles/strangles, naked put selling, synthetics |
| `04_put_spreads_leaps.md` | 22–25 | Put spreads, combination spreads, ratio put spreads, LEAPS |
| `05_arbitrage_math.md` | 26–28 | T-bill/option strategy, arbitrage, Black-Scholes/volatility math |
| `06_index_futures.md` | 29–35 | Index options, index hedging, structured products, futures options |
| `07_volatility.md` | 36–39 | Historical vs. implied volatility, IV percentile method, volatility trading rules — the most directly actionable section |
| `08_advanced_taxes_bestof.md` | 40–43 | Greeks/neutrality, VIX derivatives, option taxes, McMillan's own closing "Best Strategy?" synthesis |

Each file's own header lists exactly which OCR'd text files it was built
from and flags any gap (a source file that cut off mid-sentence) rather
than silently treating a cutoff as "chapter complete."
